# 数据库访问

全部 16 个集合的客户端读写均为 false（ADMINONLY 等效规则）。
小程序与网页后台只能调用云函数。云函数高权限访问数据库，但必须另外检查可信身份、用户封禁状态、参与者关系和管理员角色。

部署验证应同时检查控制台实际规则和小程序 SDK 直接 get/add/update 的拒绝结果。仅有本地 collections.json 不代表规则已部署。

商品图片使用 PRIVATE 云存储；客户端通过业务云函数上传压缩后的 JPG/PNG，不能直接覆盖已审核对象。文件路径由服务端生成，media.urls 只接收商品 ID 并重新校验可见性和审核结果；禁止签发任意客户端 fileID。图片临时链接有有效期，下架后停止签新链接，但先前签发的链接不会自动立即撤销。

media-callback 仅接受微信运行时 SOURCE=wx_trigger 且 AppID、事件和版本符合配置的消息；不能为了调试向客户端开放回调写权限，也不能在真实数据库手动写 PASSED 冒充审核成功。
